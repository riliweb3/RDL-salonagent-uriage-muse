# 見本：いちばんシンプルな形

ヒアリングで「お店全体の数字だけ・Notion のフォームで入力・目標はサロン全体だけ」と答えた場合の例。
答えが違えば、この形にこだわらず作り変える。

## HOME（ページ）

- このページの使い方（3行）
- 見出し「毎日」：売上記録へのリンク
- 見出し「毎月」：目標管理へのリンク
- 見出し「お店のこと」：サロンの特徴へのリンク

## 売上記録（表）

| 列 | 種類 |
|---|---|
| 名前（日付を入れる） | タイトル |
| 日付 | 日付 |
| 総売上 | 数値 |
| 客数 | 数値 |
| 新規 | 数値 |
| 次回予約 | 数値 |
| 物販 | 数値 |
| 振り返り | テキスト |

## 目標管理（表）

| 列 | 種類 |
|---|---|
| 名前（例：2026年12月） | タイトル |
| 対象月 | 日付 |
| 売上目標 | 数値 |
| 客数目標 | 数値 |
| 今月の取り組み | テキスト |

## サロンの特徴（ページ）

強み／お客さまの層／客単価／スタッフ構成／考え方 を、お店の人の言葉で書く。
ここを書くと、Muse の答えがお店に合ったものになる。
